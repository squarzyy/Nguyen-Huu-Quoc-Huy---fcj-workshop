### Week 9 Objectives:

* Gain hands-on experience building an end-to-end serverless analytics and visualization pipeline—verifying ingested data, configuring Amazon S3 query output storage, connecting via AWS Systems Manager Session Manager, querying data with Amazon Athena, and building dashboards in Amazon QuickSight.

* Master Amazon DynamoDB fundamentals and backup operations, including exploring table structures, items, indexes, and configuring on-demand/point-in-time backups.

* Explore advanced Amazon DynamoDB architectures and serverless patterns, including single-table/advanced design patterns, Global Tables for multi-region serverless applications (LMR), and Event-Driven Architectures (LEDA) powered by DynamoDB Streams.

* Practice database provisioning, data population, cost optimization, usage monitoring, and financial governance through AWS Cost Allocation Tags and advanced query result analysis.

### Week 9 Achievements:

**Serverless Data Analytics & BI Visualization (Athena & QuickSight)**
* Validated raw ingested datasets, configured Amazon S3 output locations, established secure session connections, and ran analytical SQL queries using Amazon Athena.

* Connected Athena datasets to Amazon QuickSight to build interactive visualizations and extract actionable business insights.

**Amazon DynamoDB Fundamentals, Backups & Advanced Serverless Patterns**
* Explored NoSQL data modeling in Amazon DynamoDB, practiced querying tables and indexes, and configured backup strategies to protect table data.

* Implemented advanced DynamoDB design patterns, built a multi-region global serverless application (LMR), and architected a serverless event-driven workflow (LEDA) reacting to database state changes.

**Database Provisioning, Cost Allocation & Usage Optimization**
* Prepared, built, and populated database tables while implementing cost tracking mechanisms using AWS Tagging and Cost Allocation reports.

* Analyzed service usage metrics and executed additional validation queries to verify performance and query accuracy.
