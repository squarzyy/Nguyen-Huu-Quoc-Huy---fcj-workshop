### Week 11 Objectives:

* Master visual data quality assessment and preparation using AWS Glue DataBrew by running data profiling jobs to evaluate schema statistics, anomalies, and data distributions, followed by building cleaning and transformation recipes.

* Understand and prepare end-to-end ETL (Extract, Transform, Load) pipeline prerequisites including IAM roles, storage buckets, and source/target configurations.

* Gain hands-on experience building automated serverless data pipelines with AWS Glue—ingesting and storing raw data in Amazon S3, cataloging metadata using AWS Glue Crawlers and the AWS Glue Data Catalog, and executing ETL transformation jobs.

### Week 11 Achievements:

**Visual Data Profiling, Cleaning & Transformation (AWS Glue DataBrew)**
* Executed data profiling jobs in AWS Glue DataBrew to automatically evaluate dataset quality, identify missing values or outliers, and inspect column-level statistics.

* Built and ran no-code transformation recipes to clean, normalize, and prepare structured datasets for downstream analytics.

**End-to-End Serverless ETL Pipeline (Amazon S3 & AWS Glue)**
* Configured all preparatory IAM permissions and storage structures required for automated data engineering workflows.

* Ingested and stored raw data into an Amazon S3 data lake, automatically discovered schemas and populated metadata tables via AWS Glue Crawlers, and transformed datasets at scale using AWS Glue ETL jobs.
