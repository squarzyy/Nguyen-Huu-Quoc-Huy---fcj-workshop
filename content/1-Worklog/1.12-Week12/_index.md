### Week 12 Objectives:

* Master multi-engine data transformation workflows across AWS Glue (serverless Spark ETL), AWS Glue DataBrew (no-code visual preparation), and Amazon EMR (distributed big data processing).

* Gain hands-on experience performing batch and real-time data analytics using Amazon Athena for interactive SQL queries and Amazon Kinesis Data Analytics for streaming insights.

* Practice serving transformed data via serverless compute (AWS Lambda) and loading structured datasets into an enterprise cloud data warehouse with Amazon Redshift.

* Build, refine, and publish interactive business intelligence (BI) dashboards in Amazon QuickSight to visualize key operational and analytical metrics.

### Week 12 Achievements:

**Multi-Tool Data Transformation (AWS Glue, DataBrew & Amazon EMR)**
* Executed end-to-end data transformation pipelines comparing three AWS processing paradigms: serverless ETL jobs with AWS Glue, visual no-code transformations in AWS Glue DataBrew, and cluster-based big data processing with Amazon EMR.

**Batch & Real-Time Streaming Analytics (Amazon Athena & Kinesis Data Analytics)**
* Performed serverless SQL analytics over transformed S3 datasets using Amazon Athena and processed live streaming data in motion with Amazon Kinesis Data Analytics.

**Data Warehousing & Serverless Data Serving (Amazon Redshift & AWS Lambda)**
* Loaded curated datasets into Amazon Redshift for high-performance analytical warehousing and configured AWS Lambda functions to serve processed data to downstream applications.

**Interactive Business Intelligence Dashboards (Amazon QuickSight)**
* Built comprehensive visualizations in Amazon QuickSight, iteratively enhanced dashboard layout and clarity, and implemented interactive controls for dynamic data exploration.
