### Week 1 Objectives:

* Understand fundamental Cloud Computing concepts, AWS value propositions, the Cloud Adoption Journey, and the AWS Global Infrastructure (Regions, Availability Zones, and Edge Locations).

* Explore AWS Service Management Tools and foundational strategies for AWS Cost Optimization.

* Gain hands-on experience creating and securing an AWS account, setting up a Virtual MFA device, creating an Admin Group, and configuring account authentication support.

* Master AWS Billing and Cost Management by creating various types of budgets (Template, Cost, Usage, Reserved Instance, and Savings Plans budgets), performing resource cleanup, and exploring AWS Support plans and case management.

### Week 1 Achievements:

**Cloud Computing Foundations & AWS Global Infrastructure**
* Gained a solid understanding of Cloud Computing benefits, why organizations choose AWS, the stages of the Cloud Adoption Journey, and how AWS Global Infrastructure (Regions, Availability Zones, and Edge Locations) ensures high availability and low latency.

* Explored AWS Service Management Tools and core cost-optimization pillars to architect cost-effective cloud environments from day one.

**AWS Account Setup & Foundational Security**
* Successfully created a new AWS account and implemented essential security best practices, including enabling Multi-Factor Authentication (Virtual MFA), setting up an IAM Admin Group, and configuring account authentication support.

**Financial Governance with AWS Budgets**
* Mastered proactive cost monitoring by configuring multiple budget types—Template Budgets, Cost Budgets, Usage Budgets, Reserved Instance (RI) Budgets, and Savings Plans Budgets—followed by proper resource cleanup.

**AWS Support Plans & Operational Assistance**
* Compared the features and SLA tiers across AWS Support Packages, practiced switching support plans, and learned how to open and manage technical or billing support cases via the AWS Support Center.
