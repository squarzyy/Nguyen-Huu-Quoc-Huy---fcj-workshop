### Week 10 Objectives:

* Gain hands-on experience interacting with AWS services across multiple interfaces, including browser-based AWS CloudShell, the AWS Management Console, and programmatic access via AWS SDKs.

* Practice provisioning and configuring a cloud-based integrated development environment (IDE) using AWS Cloud9.

* Master data preparation prerequisites by downloading raw datasets, uploading them to Amazon S3, and configuring AWS Glue DataBrew for visual data cleaning and transformation.

### Week 10 Achievements:

**Multi-Interface AWS Management & Cloud Development (CloudShell, Console, SDK & Cloud9)**
* Practiced managing and interacting with AWS resources across three core interfaces: browser-based terminal commands in AWS CloudShell, GUI workflows in the AWS Management Console, and programmatic API calls using the AWS SDK.

* Provisioned and configured an AWS Cloud9 instance to establish a cloud-based development environment pre-configured with AWS CLI and SDK tools.

**Data Staging & Visual Data Preparation Setup (Amazon S3 & AWS Glue DataBrew)**
* Acquired and staged raw datasets by downloading source data locally and uploading it into an Amazon S3 bucket for centralized cloud storage.

* Configured AWS Glue DataBrew to connect to S3 datasets, laying the groundwork for no-code visual data profiling, cleaning, and transformation pipelines.
