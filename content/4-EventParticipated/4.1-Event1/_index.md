# AI in Enterprise

### Purpose of the Event

- Share the differences between AI in Academic and Enterprise.
- Security in Enterprise.
- Cloud role in application.
- How to Use AI Wisely.
- How to build/config an AgentCore.

### Speaker List

- **Khang**
- **Hiếu**
- **Bảo**

### Key Highlights

- The scale and how big companies and enterprise use AWS AI AgentCore to solve their problems.
- Method to set up an Agent.
- Debug and observe Agent's outputs.
- AgentCore Map.
- Inbound and Outbound
- 
#### AgentCore

- Agent Memmory.
- Agent Observability.
- Authorization in Bedrock AgentCore Gateway.
- Current Agentic memory challenges: Storage Scalibility, Memory Refresh, intergraion Complexity, Privacy & Security Concerns, Retrieval Accuracy Problems, Observability.
- Human in the loop: Request, Proposal, Approval Gate.
- Introduce to Strands: Controlled Agent Orchestration.
- Introduce to Langfuse, an Agent Observer that trace agent workflows and tool calls.

#### Technical View

- Guard AI from harmful, exploit requests.
- Isolate between train data and user's personal data.
- Manage AI memory.

### Key Takeaways

#### Differences in Enterprise AI

- Enterprise AI is more than just a model which require more Reliability, Cost, Security, Scalability, Data Pipeline and Monitoring.
- Problems that Enterprise AI is designed for.

#### Design and Security Mindset

- Always isolate between training data and user's personal data such as email, billing address, personal information, etc...
- Scale a bit further for Agent memory to prevent bottleneck.
