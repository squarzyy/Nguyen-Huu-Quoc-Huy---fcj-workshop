###  [Blog 1 - SECURE ACCESS CONTROL FOLLOWING THE LEAST PRIVILEGE PRINCIPLE WITH AWS IAM](3.1-Blog1/)
This blog explains how to apply the Principle of Least Privilege in AWS IAM to mitigate security risks caused by over-permissioning. By adopting core practices such as using IAM Roles instead of hardcoded Access Keys, organizing permissions via IAM Groups, narrowing Action/Resource/Condition scopes in policies, periodically auditing unused permissions, and enforcing MFA, you can maintain tight access control across users and services on AWS.

###  [Blog 2 - WHAT IS EC2 & COMPUTE COST OPTIMIZATION FOR SMALL AND MEDIUM PROJECTS ON AWS?](3.2-Blog2/)
This blog outlines practical strategies to optimize EC2 and compute costs for small and medium-sized projects on AWS without sacrificing performance. It covers four key pillars: combining appropriate pricing models (On-Demand, Savings Plans/Reserved Instances, and Spot Instances), right-sizing instances including AWS Graviton processors, scheduling non-production environments to shut down off-hours, and leveraging serverless compute (AWS Lambda) for intermittent workloads.

###  [Blog 3 - WHAT IS AMAZON VPC? A QUICK GUIDE TO YOUR "PRIVATE HOME" ON AWS](3.3-Blog3/)
This blog provides a beginner-friendly overview of Amazon VPC (Virtual Private Cloud)—an isolated virtual network environment that secures and organizes your AWS resources. It walks through core networking building blocks including CIDR blocks, Public vs. Private Subnets, Security Groups, and Network ACLs, alongside essential best practices for resource naming, restricting public port exposure, and cleaning up billable components like NAT Gateways after labs.
